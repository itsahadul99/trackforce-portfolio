Section 8.1 — Google Search Console

Google Search Console Setup

Site verification meta tag ব্যবহার করে Google কে জানানো হয় যে এই domain এর আমরাই owner। Next.js Metadata API দিয়ে implement করা হয়েছে — কোনো আলাদা HTML file লাগবে না।

কিভাবে কাজ করে

Next.js metadata.verification.google field টি automatically <meta name="google-site-verification" content="..."> tag generate করে এবং সব page এর <head> এ inject করে। Env var সেট না থাকলে tag render হয় না।

Code — src/app/layout.tsx

src/app/layout.tsx TypeScript 
export const metadata: Metadata = {
  // ... other fields ...

  // GSC verification — env var সেট থাকলেই inject হবে
  ...(process.env.NEXT_PUBLIC_GSC_VERIFICATION && {
    verification: {
      google: process.env.NEXT_PUBLIC_GSC_VERIFICATION,
    },
  }),
};
Generated HTML (auto by Next.js) HTML 
<meta
  name="google-site-verification"
  content="xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
/>
.env.local ENV 
# Search Console → Settings → Ownership Verification
# → HTML tag → content="..." এর ভেতরের value টুকু copy করুন
NEXT_PUBLIC_GSC_VERIFICATION=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Activation Steps

1
Search Console এ যান

search.google.com/search-console → Add property → trackforce.com add করুন

2
Verification code নিন

Settings → Ownership verification → HTML tag → content="..." এর ভেতরের value copy করুন

3
Env variable set করুন

Production server এ NEXT_PUBLIC_GSC_VERIFICATION=copied_value set করুন এবং redeploy করুন

4
Verify ও Sitemap submit করুন

Search Console এ "Verify" click করুন → Sitemaps → submit করুন:

Section 8.2 — Google Analytics 4

GA4 Setup via next/script

next/script এর strategy="afterInteractive" ব্যবহার করা হয়েছে — GA4 script টি page interactive হওয়ার পরে load হয়, ফলে LCP বা FCP এর উপর কোনো impact নেই।

Code — src/app/layout.tsx

src/app/layout.tsx — import & config TypeScript 
import Script from "next/script";

// Env var থেকে GA Measurement ID পড়া
const GA_ID = process.env.NEXT_PUBLIC_GA_MEASUREMENT_ID;
src/app/layout.tsx — RootLayout body TSX 
<body>
  <Navbar />
  <main>{children}</main>
  <Footer />

  {/* GA_ID সেট থাকলেই scripts inject হবে */}
  {GA_ID && (
    <>
      {/* Script 1 — gtag.js লোড */}
      <Script
        src={`https://www.googletagmanager.com/gtag/js?id=${GA_ID}`}
        strategy="afterInteractive"
      />

      {/* Script 2 — GA4 initialize */}
      <Script id="ga4-init" strategy="afterInteractive">
        {`
          window.dataLayer = window.dataLayer || [];
          function gtag(){dataLayer.push(arguments);}
          gtag('js', new Date());
          gtag('config', '${GA_ID}', {
            page_path: window.location.pathname
          });
        `}
      </Script>
    </>
  )}
</body>
.env.local ENV 
# GA4 → Admin → Data Streams → Web stream → Measurement ID
NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX

কেন strategy="afterInteractive" ব্যবহার করা হয়েছে

Strategyকখন load হয়Core Web Vitals impact
beforeInteractive Page render এর আগে LCP ও FCP delay করে — avoid করতে হবে
afterInteractive ✓ Page interactive হওয়ার পরে কোনো impact নেই — আমরা এটাই ব্যবহার করেছি
lazyOnload Browser idle time এ কোনো impact নেই, তবে bounce tracking miss হতে পারে

Activation Steps

1
GA4 Measurement ID নিন

analytics.google.com → Admin → Data Streams → Web → Measurement ID copy করুন

Format: G-XXXXXXXXXX
2
Env variable set করুন

Production server এ env var set করুন এবং redeploy করুন

NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
3
Verify করুন

GA4 → Reports → Realtime এ গিয়ে site visit করুন — active user দেখা গেলে setup সম্পন্ন
