# TrackForce — Workforce Management SaaS Website

A modern marketing website for **TrackForce**, an employee productivity and workforce monitoring platform.

---

## Getting Started

### Prerequisites

- Node.js 18+
- pnpm (recommended)

### Install & Run

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:80) in your browser.

### Build for Production

```bash
pnpm build
pnpm start
```
